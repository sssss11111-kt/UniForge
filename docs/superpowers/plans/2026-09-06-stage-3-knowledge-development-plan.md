# Stage 3 Knowledge & Intelligence Development Plan

## Task order

1. **Task 3.1 Content and Source Domain** — `packages/contracts/knowledge/content.ts`, source import service, provenance tests.
2. **Task 3.2 Topic and Relation Domain** — typed relations, remove/delete semantics, permission tests.
3. **Task 3.3 Extraction Proposals** — citations, AI Generated labels, approval-gated persistence.
4. **Task 3.4 Memory Admission** — receipt/evidence/candidate/claim/outcome flow and conflict handling.
5. **Task 3.5 Derived Search and Rebuild** — rebuildable index contract, stale-index recovery, no truth duplication.
6. **Task 3.6 Decisions and Actions** — evidence-linked proposals, explicit execution approval.
7. **Task 3.7 Knowledge Workspace** — typed IPC and vertical slice for inbox, topics, knowledge, memory, and actions.
8. **Task 3.8 Stage Acceptance** — lawful-data review, security review, full gates, evidence, and user acceptance.

Each task must add its own contracts, tests, evidence, checkpoint commit, and rollback notes. Do not begin the next task until the current task is verified and its subtask is closed.

## Stage 3 acceptance

All eight task evidence files, full repository gates, permission review, provenance review, and explicit user acceptance are required before creating `stage-3-knowledge-accepted`.
