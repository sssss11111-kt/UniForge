# Stage 5 Project Practice Development Plan

## Task order

1. **Task 5.1 Project and Workspace Domain** — authorized project workspaces, canonical path checks, Git reference contracts.
2. **Task 5.2 Project Task and Goal Flow** — goals, tasks, status, dependencies, approvals, and failure evidence.
3. **Task 5.3 Project Tool Execution** — scoped build/test/CLI operations through Tool Gateway.
4. **Task 5.4 Artifacts and Decisions** — artifact provenance, review, decision and retrospective records.
5. **Task 5.5 Project Workspace** — typed IPC, Preload, Renderer vertical slice with visible task/tool states.
6. **Task 5.6 Protected-Path Security Gate** — automated tests preventing UniForge self-modification or cross-workspace access.
7. **Task 5.7 Stage Acceptance** — full gates, security review, evidence, rollback notes, and user acceptance.

Each task requires contracts, focused tests, evidence, checkpoint commit, and rollback notes. Do not start the next task until the current task is verified and its subtask is closed.

Stage acceptance requires all task evidence and explicit user acceptance before creating `stage-5-project-practice-accepted`.
