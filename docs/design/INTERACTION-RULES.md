# Interaction Rules

- Mutations show the object, command, scope, and resulting state.
- High-risk actions require an explicit approval surface.
- Denied permissions fail visibly.
- Loading and offline states never display optimistic success.
- Remove Relation, Delete, and Forget remain distinct actions.
- Agent timelines show evidence, tools, approvals, failures, cancellation, and recovery.
- Keyboard focus is never trapped without an escape path.
