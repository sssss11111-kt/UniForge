# Stage 2 lawful English data boundary

UniForge may ship contracts, services, and user supplied references, but must not bundle unverified vocabulary corpora, Cambridge or IELTS examination content, scraped answer keys, model assets, or datasets with unclear redistribution rights. Official or licensed material requires a registry entry with repository/source, pinned version, licence, Windows disposition, security review, and adoption level before inclusion.

Runtime imports remain user-authorized and provenance-bearing. Search indexes and caches are rebuildable derived state; they never become canonical English content. AI-generated material is labelled and requires approval before durable persistence.
