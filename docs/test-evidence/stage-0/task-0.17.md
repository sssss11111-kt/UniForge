## Visible blockers

`npm run security` executes `npm audit --audit-level=high` and returned exit code 1 with 24 advisories (3 low, 20 high, 1 critical). The high and critical findings are in the Electron Forge 7.11.2 dependency chain (`extract-zip`, `tar`, and `tmp` among others); npm only offered a breaking downgrade to Forge 6.4.2. No automatic dependency change was made.

`npm run verify:windows-package` validates the generated manifest and artifact hashes, then returns exit code 2 with:

`BLOCKED: clean Windows install, launch, SQLite, sidecar, uninstall, and rollback require an isolated Windows VM.`

The package build itself ran successfully on this Windows host. The clean install lifecycle remains an explicit environment gate and is not represented as a pass.
